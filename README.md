# Qué Nota Café

Sitio web one-page mobile-first para venta de café colombiano de especialidad con diseño wireframe mid-fidelity.

## 🚀 Deploy en Vercel

Este proyecto está configurado para desplegarse automáticamente en Vercel.

### Configuración del dominio

- Dominio: quenotacafe.com
- Proveedor: latinoamericahosting.com

## 📦 Tecnologías

- React 18.3.1
- Vite 6.3.5
- Tailwind CSS 4.1.12
- TypeScript

## 🛠️ Desarrollo Local

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Compilar para producción
npm run build
```

## 📱 Características

- Diseño mobile-first responsivo
- Flujo de pedido paso a paso
- Integración con WhatsApp Business
- Selección de gramaje y tipo de molienda
- Layout centrado optimizado para desktop
